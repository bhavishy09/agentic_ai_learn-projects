# Agentic AI Learning Journey

Welcome to the Agentic AI Learning Journey repository! This space is dedicated to organizing and tracking progress day by day.

## Folder Structure

The repository will be organized as follows:
```text
agentic_ai_learnings/
├── README.md
├── day1/
│   ├── [Topic-Name]/
│   │   ├── notes.md (or other files)
│   │   └── resources/ (PDFs, images, slides)
├── day2/
│   └── ...
```

Whenever you share new resources, notes, code files, or PDFs, please specify:
1. Which day it belongs to (e.g., Day 1, Day 2).
2. The specific topic or sub-topic (e.g., "Intro to LLM Agents", "Tool Use", "RAG & Vector DBs").

I will organize the files, create the folders, and format the notes accordingly!
